If you have a promo code, enter it in your account. You can go straight to the [Promo tab](https://pornx.co/account/promocode).

1. Log in and open your account.
2. Go to the **Promo** tab.
3. Enter the code and confirm.

A promo code adds tokens to your balance. If a code is rejected, check for typos and that it has not expired, then contact [support](mailto:support@pornx.co).

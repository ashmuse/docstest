The image generator has two tools that help with prompts. They work differently.

| Tool | What it does | When it runs |
| --- | --- | --- |
| Prompt Assistant | Writes a new prompt or rewrites yours | When you click it |
| Prompt Enhancer | Rewrites your prompt to make the result better | With every generation while it is on |

## Prompt Assistant

Open the Prompt Assistant from the prompt box on the [Create page](https://pornx.co/create). It offers two options:

- **Surprise me** generates a fresh random prompt.
- **Make it better** rewrites your current prompt.

The Prompt Assistant has a usage limit. The box shows how many prompts you have left. When you reach the limit, wait and try again later.

## Prompt Enhancer

The Prompt Enhancer is a switch next to the prompt box. When it is on, your prompt is rewritten before it goes to the model. When it is off, the model gets your prompt as you wrote it. The tooltip on the switch shows its current cost.

<Tip>
  If the result does not match your prompt, turn the Prompt Enhancer off. See [Generation issues](/troubleshooting/generation).
</Tip>

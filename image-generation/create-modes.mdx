The [Create page](https://pornx.co/create) has a mode switcher labeled **Creation mode**.

| Mode | Use it to |
| --- | --- |
| Image | Generate an image from a prompt, model, styles and actions. See [Image generation overview](/image-generation/overview). |
| Presets | Start from a saved combination of settings. See [Presets](/image-generation/presets). |
| Character | Generate with a saved character, or create a new one. See [Characters](/characters/overview). |

If you open Character mode with no characters yet, you are taken to character creation first.

## New layout and Classic mode

The Create page was redesigned in April 2026. If you prefer the previous layout, Classic mode is still available.

## Gallery below the prompt

Your recent generations appear on the Create page. You can switch their display between **Masonry** and **Grid** with the **Layout** control.

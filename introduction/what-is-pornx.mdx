You write a prompt. The platform runs it through a generation model and returns an image or video. No drawing, no editing software, no uploads required to get started.

## What you can do

**Generate images** from a text prompt using models, each tuned for a different visual style — photorealistic, cinematic, anime, cartoon, and others. Add LoRAs, Styles, or Actions to push the output further. Use InPaint to edit specific areas of a result.

**Generate video** by animating an image you've already created, or by writing a text-to-video prompt directly. Video output groups into Sessions so you can keep experiments organized.

**Edit images** in the Edit page with Inpaint, Upscale, Upscale Pro and Reimagine. See [Edit page](/image-generation/edit-page).

**Chat with characters** in uncensored AI roleplay, or build your own chatbot. Chat is in public beta. See [Chat overview](/chat/overview).

**Browse the Gallery** — a continuously updated feed of community-published generations, organized by category and personalized to your taste. Gallery images can be remixed or used as the first frame of a video.

## Accounts and tokens

Free accounts get four image generations per day. Premium unlocks all models, Styles, Actions, higher quality, Private Generation, and higher video resolutions. Many actions, such as video, editing and character creation, use tokens, which anyone can buy. See [/premium](https://pornx.co/premium) for current rates and plan details.

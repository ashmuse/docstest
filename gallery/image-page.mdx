Click any item in the [Gallery](/gallery) to open its page. The page shows the item, its details, related content and comments.

## Details

The **Info** panel can show the model, prompt, style, tags, resolution and type. The prompt is hidden for content generated with [Private generation](/image-generation/private-generation).

## Actions

| Action | What it does |
| --- | --- |
| Save | Adds the item to your collections. |
| Download | Saves the file to your device. |
| Share | Shares a link to the page. |
| Recreate or Reuse | Opens the generator with the original settings so you can make a variation. |
| Edit | Opens the item in the [Edit page](/image-generation/edit-page). |
| Image to video | Sends the image to the [video generator](/video-generation/image-to-video). |
| Comments | Opens the comments. |
| Report | Reports content that breaks the [Community guidelines](/help-section/community-guidelines). |
| Delete | Deletes the item. Shown on your own creations. |

You can also vote on items in the feed. Votes feed the recommendations. See [Gallery](/gallery).
